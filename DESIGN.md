# Архитектура Bulls and Cows

## Структуры данных и алгоритмы

Секрет и попытка — строки. Это сохраняет ведущий ноль (`0123`) и делает сравнение цифр по позиции прямым. Система счисления представлена числом `2 | 8 | 10 | 16`; оно определяет срез алфавита `0123456789abcdef`.

`RoundState` в `src/game/round.ts` содержит настройки, секрет, время начала и завершения, статус и массив `history`. Каждая запись `GuessEntry` хранит попытку, `bulls` и `cows`. `submitGuess` возвращает новый объект раунда и новый массив `[...history, entry]`. Старый объект и старые записи не меняются. Некорректная или повторная попытка возвращает прежний объект. `RecordEntry` хранит длину и базу вместе с числом попыток и временем, поэтому общая таблица рекордов показывает условия каждого результата. `rankRecords` копирует список, сортирует по числу попыток, затем по времени, и оставляет десять лучших. Только `src/main.ts` читает и пишет `localStorage`.

`generateSecret` в `src/game/generateSecret.ts` частично перемешивает массив цифр алгоритмом Фишера — Йетса. На каждом шаге выбирается одна из ещё не занятых позиций через переданный `random`. Передача источника случайности позволяет проверять результат детерминированно.

`evaluateGuess` в `src/game/evaluateGuess.ts` приводит обе строки к нижнему регистру. Первый `filter` считает цифры, совпавшие на своих позициях. Второй `filter` считает цифры на других позициях, которые есть в секрете. Игра вызывает функцию только после проверки уникальности цифр попытки, поэтому каждая корова учитывается один раз.

`createDigitValidator` возвращает предикат для одной цифры выбранной системы. Его используют `isValidGuess` в `src/game/isValidGuess.ts` и обработчик поля ввода в `src/main.ts`. Сравнение после `toLowerCase()` делает `A` и `a` одной hex-цифрой.

`countPossibleSecrets` в `src/game/countPossibleSecrets.ts` считает перестановки с ведущим нулём. Внутренняя рекурсивная функция применяет `P(available, length) = available × P(available − 1, length − 1)` с базой `P(available, 0) = 1`. Результат каждого подвычисления сохраняется в `Map` по паре `(length, availableDigits)`.

## Сложность

Здесь `n` — длина секрета/попытки, `b` — число цифр в системе счисления.

| Функция                | Время                                             | Дополнительная память              | Почему                                                                                                                                             |
| ---------------------- | ------------------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generateSecret`       | `O(b + n)`                                        | `O(b)`                             | Создаётся массив из `b` цифр, затем выполняются `n` обменов.                                                                                       |
| `evaluateGuess`        | `O(n²)`                                           | `O(n)`                             | Два массива длины `n`; второй `filter` для каждой цифры может вызвать линейный `includes`.                                                         |
| `isValidGuess`         | `O(n × b)`                                        | `O(n + b)`                         | `every` проверяет до `n` символов по алфавиту длины `b`; `Set` содержит до `n` цифр. При заданных базах `b ≤ 16`, фактически время линейно по `n`. |
| `countPossibleSecrets` | `O(n)` при первом вызове, `O(1)` для готовой пары | `O(n)` на стек и новые записи кэша | Рекурсия уменьшает длину на единицу; уже посчитанная пара берётся из `Map`.                                                                        |

## Принципы чистого кода

- **Понятные имена:** `generateSecret`, `evaluateGuess`, `finishedAt`, `availableDigits` прямо описывают действие или значение. Нет числовых индексов с неясным смыслом в публичных типах.
- **Одна ответственность:** файлы `src/game/*.ts` содержат отдельные функции правил игры. `src/main.ts` отвечает за DOM и хранение рекордов, а `round.ts` — за переходы состояния.
- **DRY:** одна функция `createDigitValidator` определяет допустимость символа и для полной попытки, и для ввода. `createSettingsControls` строит настройки до и после старта, меняя только доступность полей.
- **KISS и YAGNI:** в проекте нет классов, сервера, внешней библиотеки для игровой логики и лишних режимов. Чистые функции получают случайность и время параметрами, поэтому их тесты не требуют браузера.
- **Семантическая разметка:** `src/main.ts` создаёт `header`, `main`, `section`, `aside`, `form`, `ol` и связанные `label`. `index.html` оставляет `body` пустым, кроме подключаемого модуля.
